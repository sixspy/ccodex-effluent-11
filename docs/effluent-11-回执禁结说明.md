# effluent-11 回执禁结拍板说明（当日锁死）

> 生效日期：2026-11-25。拍板后锁定，旁门不要；偏离本说明的任何结案写口一律记
> `回执禁结偏航` 审计痕并拒写正式区。

## 1. 背景

外送化验空桩回执尚未回到，排放批却把“结案完成态”写入正式册 SM-K11：空桩页仍显示
待回，对账侧已宣告完结。两边口径混用，导致无回执仍出正式完成。

## 2. 正确性总口径（两边不得混用）

- **外送回执到达**：只许写空桩回执列（`lab_courier_receipts`，状态 `已签收`），
  写口为 `POST /api/stubs/lab-courier/{job_id}/receipt`，不触碰任何结案表。
- **结案完成写库**：只许在回执列已存在 `已签收` 记录时，写正式册
  `case_complete_registry` 并把采样推进到 `已结案`。
- 两个写口分属不同服务（空桩服务 / 准排服务），禁止互相代填、禁止单点回执空判交差。

## 3. 两条允许路径（拍板保留两条，出口唯一：无回执绝不出正式完成）

### 甲路径（formal，默认）

回执列空 → 准排服务结案键当场拒写（HTTP 400）：

- 正式册 `case_complete_registry` 零行；
- 采样完成态零改（停在 `已封批`）；
- 许可配额台账 `permit_quota_ledger` 零扣；
- 审计写 `回执禁结偏航`。

### 乙路径（shadow）

回执列空 → 结案只许登记影子区 `shadow_case_closings`（`待回报草稿`）：

- 正式区零改、配额零扣、采样状态零改；
- 回执到达后走原子升正：同事务内写正式册一条、旧影子草稿置 `草稿作废`、
  采样置 `已结案`、配额扣一次；正式区零改时草稿永远停在待回报/作废，绝不双写。

## 4. 对账互斥（对账服务）

- 对账完结灯 `closed_complete` 与空桩待回互斥：许可下存在回执列空的外送采样，
  或存在 `待回报草稿` 影子，即 `closed_complete=false`、`balanced_finalized=false`，
  原因列入 `blockers`。
- 影子完成不计入结案；正式结案数只认 `case_complete_registry`。

## 5. 许可配额（许可服务）

配额扣减推迟到回执到达、正式升正的同一事务内（`permit_quota_ledger`，
`UNIQUE(sample_id)` 同批只扣一次）。影子草稿与被拒请求零扣减。

## 6. 批锁争用（锁服务）

两路会话同时对同批（`sample:{id}`）抢完成态：

- 进程内实时门闩 + SQLite `effluent_locks` 双重串行，后到者 HTTP 409；
- 败方只在 `contention_log` 记一条 `争用失败`，正式完成态零写、采样状态零改。

## 7. 五页同态

空桩页（回执列/待回）、准排页（结案键+待回警示）、对账页（完结灯互斥）、
许可页（已扣配额笔数）、总览页（待回外送数=空桩页口径）共用同一后端字段，
禁止只改空桩页旋转图标类的表面功夫。
